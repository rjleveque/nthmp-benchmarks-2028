# NTHMP 2028 Benchmarking Workshop Problems

These problems are under development for possible inclusion in the next
NTHMP Benchmarking Workshop, tentatively scheduled for 2028.

These pages are built using [Jupyter Book](https://jupyterbook.org)
based on the repository
[](https://github.com/rjleveque/nthmp-benchmark-problems), which
also contains sample code to run the benchmark problems and produce some
of the plots and animations shown on these pages.
