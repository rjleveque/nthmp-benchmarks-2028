# nthmp-benchmarks-2028

For developing problems for the next NTHMP benchmarking workshop
planned for 2028.

This repository is currently private but later we could make public for
sharing the problems more broadly.

**Collaborators:** 

- Please create a new subdirectory within the `nthmp28` directory, with
  a descriptive name for any new problem you are working on developing
  (e.g. `nthmp28/radial_bowl`).
- Create subdirectories within problem directories for experiments with
  the modeling software you are using (e.g. `nthmp28/radial_bowl/geoclaw`).
